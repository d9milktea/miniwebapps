# 🎮 應用合集 (GitHub Pages)

這是一個包含多個小型應用與遊戲的 GitHub Pages 專案，所有應用都可以直接在網頁瀏覽器中使用。

|------------------|------------|
| 👁 **視力測驗**  | [eyevisiontest.html](eyevisiontest/eyevisiontest.html) |
| ⚫ **五子棋**    | [gomoku.html](gomoku/gomoku.html) |
| ⚫ **翻轉棋/黑白棋**    | [reversi.html](reversi/reversi.html) |

## 🚀 如何使用

1. 點擊上方的連結，即可進入相應的應用程式。
2. 本專案會不定期新增更多遊戲與工具，敬請期待！

## 🌍 部署到 GitHub Pages

如果你想在自己的 GitHub Pages 上運行這些應用：
1. **Fork** 或 **Clone** 本專案。
2. 在 GitHub 專案 **Settings** > **Pages** 啟用 **GitHub Pages**。
3. 設定 `index.html` 為首頁，然後使用 `https://your-username.github.io/your-repo/` 來存取你的專案。
